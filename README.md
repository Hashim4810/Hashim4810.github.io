### Academy Cinemas

This page is an example home page for a movie theater, styled using Bootstrap 5 and custom CSS. It contains a sticky navbar with a "Now Playing" dropdown and search bar, a logo header, movie cards for Ben-Hur, The Day the Earth Stood Still, and Vertigo with posters, descriptions, cast, and show times, a ticket form for choosing a movie, show time, and number of tickets, a contact form, and a footer with contact info, quick links, and social media links.

### Creating CSS Effects

This project practices CSS hover effects and animations. It contains a sticky navbar with a dropdown "Images" rollover menu that links to each image, and three images that each have a different effect: a dark overlay fade on hover, a zoom-in on hover, and an animated circle burst that grows across the image on hover. It also has a footer. It is built using HTML and CSS, using transitions, transforms, and keyframe animations.

### Introduction to Bootstrap

This project is an introduction to the Bootstrap 5 framework. It uses Bootstrap's grid system (a container, a row, and three equal columns) to display three beach photos side by side. It is built using HTML and Bootstrap, loaded from a CDN.

### One Page Website

This is a single-page website for an automobile enthusiasts club. It uses a navigation bar with HTML bookmarks that jump to each section on the page: a home section with a welcome message, a supercar picture gallery, a sign-up form for the auto club, an embedded video section, and a footer. It is built using HTML.

### Portfolio Website

This is my personal portfolio website, hosted live on GitHub Pages. It contains a fixed navbar, a banner with a looping background video, About, GitHub, and Contact sections with photos, a contact form, hover effects, and animations. It is built using HTML and CSS.

### Simple Recipes

This page is a recipe website for easy home cooking. It contains a navbar with a dropdown menu that links to each recipe category, a featured recipe (Deep Dish Skillet Pizza), and recipe cards for Saucy Tortelloni Parm, Mediterranean Chicken Thighs, Crispy Pork Katsu & Rice, Cheddar Cheese Biscuits, Baked Cod & Scalloped Potatoes, and S'mores Cake, each with a photo, prep time, and difficulty level. It also has an About section, a contact form with a weekly recipe subscription checkbox, and a footer with the address and phone number. It is built using HTML and CSS.

### The Pet Shop Website

This page is a website for a local pet shop. It contains a navbar that links to each animal section, a header with a quote from Anatole France, photos of cats, dogs, rabbits, fish, bearded dragons, and guinea pigs, an embedded video, and a footer with the shop's address and phone number. A separate Contact page has a form with name, email, phone number, a newsletter checkbox, and a message box. It is built using HTML and CSS.
